# 🎓 RMS — Result Management System

A full-stack **Result Management System** built with modern web technologies.  
This project manages student records, courses, results, and administration in an intuitive way with role-based access.

---

## ✨ Features

### 👩‍🎓 Student
- Secure login & profile management
- View courses, grades, and attendance
- Download report cards
- Notifications & announcements

### 👨‍🏫 Teacher
- Manage courses and subjects
- Mark attendance
- Upload results
- Communicate with students

### 🛡️ Admin
- Manage students, teachers, and staff
- Add/update courses and subjects
- Generate reports and analytics
- Role-based access control (Student / Teacher / Admin)

---

## 🛠 Tech Stack

- **Frontend:** React + Vite, TailwindCSS, React Router
- **Backend:** Node.js + Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Authentication:** JWT (JSON Web Tokens), bcrypt
- **Deployment:** Vercel, MongoDB Atlas (Database)
